# SerialX 登录页与品牌图标设计

## 目标

将已确认的「A1 · 序列轨道」视觉方案落地到 SerialX 管理台登录页，并统一网页与 IntelliJ IDEA 项目图标。变更只涉及视觉资源与登录页布局，不改变认证接口、表单校验、令牌存储或路由行为。

## 视觉方向

- 主色使用现有深蓝 `#172332` 与品牌蓝 `#2463B5`，保持管理台现有主题。
- Logo 由连续的 `S` 轨迹与独立的 `X` 交点构成，表达序列生成与分布式交汇。
- 登录页左侧使用深蓝品牌叙事区，同心轨道表达稳定边界与横向扩展。
- 右侧保留浅色登录表单，以清晰、可信、低干扰为主要体验。

## Logo 资源

新增一份项目内可复用 SVG 源文件，图形必须在小尺寸下保持清晰，并避免外部字体和图片依赖。

Logo 同步到以下位置：

1. 登录页品牌区：直接引用 SVG 资源，不复制图形路径。
2. 浏览器图标：更新 `serialx-web/public/serialx.svg`，继续由现有 `index.html` 引用。
3. IDEA 项目图标：新增 `.idea/icon.svg`，使用相同图形与配色。

不生成额外 PNG、ICO 变体；现有浏览器已使用 SVG 图标，IDEA 也使用 SVG 项目图标即可满足本次需求。

## 登录页布局

桌面端采用左右双栏：

- 左侧展示 Logo、产品标语与简短定位文案。
- 背景使用纯 CSS 绘制同心轨道和轻微斜向光带，不增加位图资源。
- 右侧承载现有 Element Plus 表单，保留账号、密码、显示密码、提交加载态与帮助文案。

移动端改为上下布局：

- 顶部压缩为 Logo、产品名和单行核心标语。
- 表单卡片置于主要可视区域，避免装饰抢占输入空间。
- 页面允许在低高度设备上自然滚动，不裁切表单或错误提示。

## 行为与错误处理

登录调用继续使用 `login()`，成功后继续保存访问令牌和当前用户并跳转首页。表单校验、重复提交保护、服务端错误展示和 Enter 提交行为保持不变。

Logo 为装饰与品牌组合：可见品牌文字由页面标题提供，SVG 图片使用空替代文本，避免屏幕阅读器重复朗读。

## 修改范围

- `serialx-web/src/views/LoginView.vue`
- `serialx-web/src/assets/serialx-logo.svg`（新增）
- `serialx-web/public/serialx.svg`
- `.idea/icon.svg`（新增）

不修改公共主题变量、认证 API、路由、依赖或后端代码。

## 验证

1. 执行 `npm run build`，确认 Vue 类型检查和生产构建通过。
2. 对本次修改文件执行 ESLint 检查，避免被仓库存量问题干扰。
3. 浏览器验证未登录访问、空表单校验、密码显隐、Enter 提交和加载态。
4. 检查桌面布局与 375px 窄屏，确认无横向滚动、内容裁切和低对比度文本。
5. 确认网页图标与 `.idea/icon.svg` 均能独立打开并显示同一品牌图形。

## 风险与边界

- IDEA 可能需要重新打开项目后才刷新项目图标，这是 IDE 缓存行为。
- 本次不制作完整品牌规范、深色主题变体、动画 Logo 或多格式导出。
- 不进行真实后端账号登录写入；浏览器流程验证使用现有环境或本地假接口。
