# SerialX 管理台导航与用户管理设计

## 目标

重新设计后台管理菜单栏与用户管理页面，在不增加后端接口、不改变现有路由和用户管理业务能力的前提下，建立清晰的导航层级并提升约 20 个控制台账户的浏览与操作效率。

## 设计方向

采用已确认的「A · 分层治理台」方案：保留深色左侧导航，与登录页的深蓝品牌语言一致；内容区使用克制的浅色背景、增强列表和低噪音操作菜单。

## 导航结构

现有路由保持不变，仅调整菜单分组、显示名称和视觉层级：

- 工作台
  - `/`：运行概览
- 资源中心
  - `/namespaces`：命名空间
  - `/apps`：应用接入
  - `/nodes`：服务节点
- 观测运维
  - `/stats`：调用统计
  - `/alarms`：告警中心
- 平台治理
  - `/users`：用户与权限
  - `/settings`：系统设置

侧栏使用项目现有 Logo，品牌区、分组标题、菜单项和账户入口形成四级层次。当前菜单项使用左侧品牌蓝指示线与深色底面，不增加动画库。桌面侧栏保持完整文字；760px 以下收为 64px 图标栏，菜单项保留 `title` 与 `aria-current`。

顶部栏继续展示面包屑和环境标识，不新增全局搜索、消息中心或虚构告警数量。

## 用户管理页面

页面标题调整为“用户与权限”，副标题为“管理控制台成员、角色及访问状态”。标题区只保留主操作“新建用户”。

筛选区收为单行工具栏：

- 关键字搜索：姓名、账号或邮箱，与现有后端查询能力一致。
- 状态筛选：继续使用现有后端 `status` 参数。
- 右侧显示后端分页结果的 `total`，不计算或展示不准确的启用用户数量。

列表适配约 20 个账户，字段如下：

1. 成员：头像、显示名称、用户名、账户 ID。
2. 联系方式：邮箱、脱敏手机号；缺失值使用明确的“未填写”。
3. 角色：将 `ADMIN`、`OPERATOR`、`VIEWER` 显示为“管理员”“运维”“只读”，未知角色回退显示原始值。
4. 状态与活动：使用状态点和“正常 / 已禁用”文字，并显示最后登录时间；从未登录时显示创建日期。
5. 操作：每行只保留“更多”菜单，包含编辑、启用或禁用、重置密码、删除。

删除 `admin` 用户继续禁用。启停、编辑、重置密码和删除仍调用现有 API；启停失败时恢复原状态。

## 数据与格式化

页面复用 `AdminUser` 已有字段：`id`、`username`、`displayName`、`email`、`mobile`、`status`、`roles`、`lastLoginAt`、`createdAt`。

新增的前端展示辅助函数只处理以下内容：

- 角色代码到中文标签的映射。
- 手机号中间四位脱敏；缺失手机号不伪造数据。
- 日期时间本地化显示；无效或缺失日期回退为“从未登录”或“-”。
- 根据用户名稳定选择现有主题色系中的头像颜色。

不新增状态管理、日期依赖或通用组件抽象。

## 操作与错误处理

- 新建和编辑继续使用现有表单弹窗与校验规则。
- 状态切换从表格开关移入更多菜单，但仍使用现有更新接口。
- 删除继续使用二次确认，并明确操作不可撤销。
- 请求失败继续显示服务端错误信息或现有中文兜底文案。
- 列表加载时保留 `v-loading`，无记录时使用 Element Plus 空状态。

## 响应式设计

- 桌面端显示全部字段。
- 1000px 以下隐藏联系方式列，将邮箱移到成员信息的辅助行。
- 760px 以下侧栏收为图标栏；筛选工具栏允许换行，操作菜单保持可点击。
- 不将用户列表改为卡片瀑布流，保持列表扫描效率。

## 修改范围

- `serialx-web/src/components/layout/BaseLayout.vue`
- `serialx-web/src/views/UserManagementView.vue`

不修改路由、API 类型、后端接口、数据库、全局主题变量或其他业务页面。

## 验证

1. 执行 `npm run build`，验证 TypeScript 与生产构建。
2. 对两个修改文件执行 Prettier 和 ESLint 检查。
3. 浏览器验证所有菜单路由、激活态、账户下拉菜单和退出登录。
4. 使用本地假接口或现有环境验证搜索、状态筛选、分页、弹窗、启停回滚、重置密码和删除确认。
5. 验证 1440px、1024px 和 375px 三种宽度，无横向溢出、字段重叠或不可达操作。

## 边界

- 本次不增加批量操作、邀请流程、自定义角色、权限矩阵、头像上传或用户详情页。
- 本次不提供角色筛选，避免在后端尚未支持该查询条件时产生只筛选当前页的误导行为。
- 不展示活跃用户数、禁用用户数等当前接口无法准确提供的全局统计。
